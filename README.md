# 合同管理系统 Contract Register

上传英文合同后，系统先在本机识别文字（扫描件也支持），把银行账号、税号等敏感信息遮盖掉，再交给大模型（DeepSeek / 通义千问等）提取服务范围、每一项金额、付款计划、里程碑和关键条款。提取结果经人工复核确认后入库，可以随时查询、导出。

## 第一次使用

1. **确认已安装 Python 3.10 – 3.14**
   如果没有安装，到 <https://www.python.org/downloads/> 下载，安装时勾选 **Add python.exe to PATH**。
2. **双击 `start.bat`**
   第一次运行会自动创建独立的运行环境并安装依赖，需要联网，大约 3–5 分钟。以后每次启动只需几秒。
3. 浏览器会自动打开 <http://localhost:8000>。
4. 进入 **设置**：
   1. 选择服务商（DeepSeek / 通义千问）。
   2. 填入 API Key。
   3. 点 **测试连接**，成功后点 **保存**。
5. 回到 **合同台账**，点 **上传合同**。

> 关闭黑色命令行窗口，系统就会停止。

## 让同事也能访问

双击 `start_lan.bat`（不要用 `start.bat`）启动。窗口里会显示一个 `http://192.168.x.x:8000` 这样的地址，同事在浏览器里打开这个地址即可访问。

- 第一次启动时，Windows 防火墙可能会弹窗询问，选择 **允许（专用网络）**。
- 系统没有登录密码，只建议在公司内网使用。

## 使用流程

| 步骤 | 说明 |
|---|---|
| 上传 | 支持 PDF（含扫描件）、Word (.docx)，可以多选、拖拽；同一份文件重复上传会自动跳过 |
| 自动处理 | 依次是：识别文字（扫描件用本机 OCR）→ 遮盖敏感信息 → AI 提取。一份 20 页的扫描件大约需要 1–2 分钟 |
| 复核 | 打开合同，对照右侧原件核对，每个字段旁边的 `p.3` 可以跳到原文对应页。有错误点 **编辑** 修改，核对无误后点 **确认复核** |
| 查询 | **合同台账**：按合同号、名称、乙方、内容关键词（中英文都可以，也会搜原文）检索<br>**明细查询**：跨合同查每一项服务、模块或货物的金额 |
| 导出 | 两个页面都可以 **导出 Excel**，包含合同、明细、付款三个工作表 |

**金额明细** 页面顶部会自动核对“各项明细之和”是否等于“合同总额”，对不上会标红提示。

## 数据与隐私

- 所有数据都在程序目录下的 `data` 文件夹里：
  - `data/contracts.db`：数据库，单个文件
  - `data/files/`：合同原件
  - `data/config.json`：AI 设置，包含 API Key
- 发给 AI 的只有遮盖后的文本。在合同详情的 **原文 → 发送给 AI 的文本** 里，可以看到实际发出去的内容。
- 遮盖的内容包括：银行名称/地址/账号、SWIFT/CNAPS/IBAN、税号、VAT 号、公司注册号、9 位以上的长数字串。合同金额（如 696,000）不会被遮盖。

## 备份与迁移

- **备份**：进入 **设置 → 下载备份**，会得到一个 zip 文件；也可以直接复制整个 `data` 文件夹。
- **恢复 / 换电脑**：
  1. 把整个程序文件夹复制到新电脑（`.venv` 文件夹可以不复制）。
  2. 把备份里的 `data` 文件夹放回程序目录。
  3. 双击 `start.bat`。

## 常见问题

- **安装依赖失败**：公司网络可能需要代理。可以先在命令行设置 `set HTTPS_PROXY=http://代理地址:端口`，再运行 `start.bat`。
- **AI 提取失败**：在合同详情里能看到具体的错误原因。修正设置后，点右上角 **⋯ → 重新 AI 分析**。
- **提示“输出被截断”**：合同明细很多时会出现。在设置里把“最大输出 tokens”调大（DeepSeek 最大 8192，qwen-plus 可以设到 16384），或者换用 `qwen-max`。

## 目录结构

```
app/            程序代码（Python 后端 + Vue3/Element Plus 前端，已内置，无需联网加载）
data/           数据（首次运行自动创建）
start.bat       启动（仅本机访问）
start_lan.bat   启动（同事可通过内网访问）
requirements.txt
```
